# a-flipper-zero-basusb-code
Lightweight BadUSB payload for Flipper Zero.  Not made to destroy any device — only creates temporary lag.  Opens Notepad + countdown, then floods Chrome with hundreds of tabs.  Ends with a “done” message so you can unplug.  No files deleted, no permanent changes.  Windows now, Android &amp; more planned.  Made by: @flpr0.fkwindows932
